# Identidade visual

Fontes consultadas em 02/09/2026:

- Site oficial: https://inventuspower.com/
- Logotipo original, sem alterações: https://inventuspower.com/wp-content/uploads/inventus-power-logo.svg
- Ícone oficial: https://inventuspower.com/wp-content/uploads/cropped-Favicon_2024_V1-192x192.png

O SVG original usa laranja `#F99B1C` e cinza `#797D82`, além de variações pontuais. A paleta CSS do site oficial usa `#FF9800`, `#20296E`, `#141414`, `#404042`, `#54585A`, `#888B8D`, `#D9D9D9`, `#F2F2F2` e branco.

O aplicativo usa o logotipo original sobre fundo branco, laranja nas ações, cinza no menu e azul nos gráficos. Verde permanece apenas como indicador semântico de situação conforme/sincronizada. As adaptações da interface não constituem um manual corporativo homologado.
